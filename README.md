# Time-Series Forecasting in PyTorch

Chapter 13 of Hands-On Machine Learning on a real series: Chicago Transit Authority daily rail ridership, 2001-2021. Clean the data, set the naive baselines every forecaster has to beat, window the series, and train a linear model, an RNN, a GRU and an LSTM on the same windows, then forecast two weeks ahead and save a working forecaster.
